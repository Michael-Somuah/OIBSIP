# Oasis Infobyte Web Development Internship - Level 2 Task 1

## Project Overview
This repository contains my submission for **Level 2 - Task 1 (Calculator)** as part of the Oasis Infobyte Web Development and Designing Internship program. 

The goal of this project is to build a fully functional, responsive, and visually appealing web-based calculator capable of performing standard mathematical operations.

## Features
* **Basic Arithmetic Operations:** Addition, subtraction, multiplication, and division.
* **Clear & Delete Functions:** Reset the calculator screen or clear individual character inputs.
* **Responsive UI:** Built to adapt seamlessly to desktop, tablet, and mobile screens.
* **Interactive Controls:** Instant visual feedback on button clicks and keypress inputs.

## Tech Stack
* **HTML5:** Semantic structural layout.
* **CSS3:** Custom styling and layout using modern design principles.
* **JavaScript:** Core functional logic and DOM manipulation.
