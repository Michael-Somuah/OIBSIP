# Overview
This project transforms traditional historical biography into an engaging, human-first digital narrative. Rather than relying on rigid dates and textbook bullet points, the tribute highlights Nkrumah's personal grit, charismatic leadership, and complex historical arc—from his humble origins in Nkroful to leading Ghana to independence in 1957.

# Key Features
Human-Centered Storytelling: A multi-paragraph biography written with a focus on personal struggle, resilience, and vision.

Responsive Timeline: A styled chronicle of key historical milestones spanning from 1909 to 1972.

Editorial Typography: Styled using Google Fonts (Space Grotesk for modern display headings and Literata for elegant body serif readability).

Quote Callout Block: Prominently styled quotes highlighting Nkrumah's core political philosophy.

Adaptive Design: Fully responsive layout built with CSS Flexbox and Grid, optimizing readability on mobile, tablet, and desktop screens.

Accessible & Semantic HTML: Built with standard HTML5 elements (<header>, <main>, <section>, <figure>, <footer>) for web standards and screen reader support.

# Tech Stack
HTML5: Semantic structural markup.

CSS3: Custom layout system using Flexbox, CSS Grid, media queries, and design variables.

JavaScript: Lightweight UI interactions and navigation.

Typography: Space Grotesk & Literata via Google Fonts.

Media Assets: Public domain historical portrait sourced from Wikimedia Commons (The National Archives, UK).
